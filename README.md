## 🔍 How the Analysis Works

The platform performs several tasks to find potential trades.

- Feature Engineering: The software creates indicators from raw price history. These indicators reveal trends, momentum, and volume shifts.
- Machine Learning Models: The system uses two models, LightGBM and XGBoost. These tools compare current market data against historical successes.
- Walk-Forward Backtesting: This process tests the models against past market data. It confirms that the predictions hold weight over different time periods.
- Continuous Retraining: The system updates its logic as new market data arrives. This ensures the analysis stays current with recent price movements.

## 📋 Frequently Asked Questions

What does the software buy for me?
The software does not buy stocks. It provides analysis to help you make informed decisions. You choose whether to act on these suggestions through your own brokerage account.

Is my data private?
Yes. The software runs entirely on your computer. No financial data leaves your local machine.

Can I change the settings?
Yes. Open the Settings menu to adjust risk levels and the types of stocks the software tracks.

What if the program stops?
Check your internet connection. If the connection drops, the platform pauses its data collection. Restart the application to resume the process.

## 🛠 Troubleshooting

If the software fails to open:
- Verify that your Windows version is up to date.
- Restart your computer.
- Ensure your antivirus software does not block the application. You can add the installation folder to your exclusion list.

If the analysis shows no results:
- Check your internet connection.
- Ensure you selected a valid list of stock symbols.
- Allow more time for the initial data download.
